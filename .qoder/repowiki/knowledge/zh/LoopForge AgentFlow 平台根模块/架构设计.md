根目录作为单一 Go module（agentflow）的装配层，将职责拆分为多个子模块并由 Go embed 与 compose 串联：
- cmd_binaries 提供 agentflow / agentflow-mcp / agentflow-runner / agentflow-account-init 等可执行入口，调用 backend_core 中的 Gin API、工作流引擎、GORM 持久化与 Runner/MCP/浏览器横向服务。
- web_app 与 chatbot_ui 是独立 npm SPA，通过 Go embed 编译进二进制，由 backend_core 直接对外暴露静态资源；deploy_scripts 的安装器与 docs 的 OpenAPI 3.1 契约同样被 embed，使单一镜像同时承载运行时与静态资源。
- migrations 以序号递增 SQL 驱动 MySQL 库表演进，e2e_tests 与 webtest_harness 分别覆盖真实部署与前端 UI 行为。
- 所有组件通过 compose.yaml（mysql + platform 两个 service）和 .env.example 提供的 AGENTFLOW_* 环境变量进行装配，Makefile 在 run/build/test/coverage 目标中串联 Go、npm、Docker 与 e2e 脚本，形成从源码到镜像的统一流水线。

- Go 代码集中在 backend_core 与 cmd_binaries 下，前端独立为 web_app 与 chatbot_ui 两个 npm 工程，通过 Makefile 与 scripts/* 桥接。
- 外部静态资源（web/、chatbot/、docs/openapi、deploy/installer）统一通过 Go embed 打包进二进制，避免运行时依赖文件系统。
- 运行时配置一律通过 AGENTFLOW_* 环境变量注入，compose.yaml 与 .env.example 共同定义默认值与必填项。
- 数据库变更采用 migrations/ 下的序号递增 SQL 文件，配合 GORM 自动迁移与种子数据注入。

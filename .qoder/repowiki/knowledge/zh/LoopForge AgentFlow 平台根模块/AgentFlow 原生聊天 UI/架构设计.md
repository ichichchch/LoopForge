模块以 `src/main.jsx` 为入口，通过一个 `Boundary` 错误边界挂载 `<App />`；`App.jsx` 是唯一的页面级组件，集中管理 sidebar、panel、dialog、menu、draft、theme 等全局状态，并组合所有子视图（`SidePanel`、`ArtifactPanel`、`ChangesPanel`、`AgentBrowser`、`NativeApprovalPanel`、`SopRunPanel`、`WorkspaceIDE`、`QuickAccessWizard` 等）。

- 状态层：`useChat.js` 暴露核心 hook，封装用户、项目、会话、模型、执行器、生成中状态与 SSE 流式回复，并通过 `message-queue.js` 实现“发送队列”——在上一轮回复完成前排队后续消息；`useLocalConversations.js` 在其外层包装本地草稿与离线模式。
- API 层：`api.js` 统一 `fetch` 调用、错误包装、附件 URL 构造、回复解析与 artifact 收集；`platform.js`、`operations.js`、`activity.js`、`runs.js`、`session-history.js`、`session-status.js`、`session-unread.js`、`session-sections.js` 等纯函数模块负责数据转换与展示逻辑。
- 运行时集成：通过 `window.parent.postMessage` 与宿主 workbench 通信（打开视图、切换 session、主题同步），Vite dev server 将 `/api`、`/mcp`、`/vscode*` 代理到 `LOOPFORGE_API`，构建产物输出到 `../web/native-chat`。
- 测试：`tests/` 下使用 Vitest + jsdom + @testing-library/react，按功能域一文件一对应测试用例。

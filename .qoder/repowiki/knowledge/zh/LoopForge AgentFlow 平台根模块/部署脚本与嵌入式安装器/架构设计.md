模块分为两个互补的子目录：
- `deploy/`：Go 包，仅通过 `//go:embed bind-cli.sh` 把 `bind-cli.sh` 打包进二进制，由 `BindCLIScript()` 暴露字节内容，供服务端 `/runners/install.sh` 端点直接返回，使远端机器可通过 `curl ... | bash` 安装 runner。
- `scripts/`：按职责划分的运维脚本集合，入口是 `install.sh`（检测依赖 → 安装 Docker/Compose → 生成 `.env` → 拉取或从源码构建 platform 镜像 → 启动 compose → 安装 schema extensions），并调用 `configure.sh`、`docker-access.sh`、`ghcr-mirror.sh`、`install-address.py`、`install-compose.py`、`install-schema-extensions.sh` 等子脚本；`build-binaries.sh` 负责用 `go build -p=JOBS` 并行编译 agentflow-runner/gate-mcp/account/mcp 等产物，支持 `--helpers` / `--platform` 模式与多 OS/ARCH 交叉编译。
依赖方向单向：`install.sh` 组合所有辅助脚本，测试脚本 `test-install.py` 通过临时根目录 + mock docker/sudo/id 验证安装流程，不反向依赖业务代码。

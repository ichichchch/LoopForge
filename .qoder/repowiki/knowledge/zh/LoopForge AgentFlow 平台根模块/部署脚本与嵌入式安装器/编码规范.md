- Shell 脚本统一以 `#!/usr/bin/env bash` 开头并立即 `set -euo pipefail`，错误处理通过自定义 `fail()`/`step()`/`info()`/`warn()` 函数输出到 stderr 后退出。
- 需要 root 权限的操作统一通过 `as_root`（来自 `docker-access.sh`）包装，非 root 用户且无 sudo 时直接失败，避免交互式密码提示。
- `.env` 文件通过 Python 的 `secrets.token_hex` 生成随机密钥，并以 `0o600` 权限创建，路径值一律经 `shlex.quote` 转义后再写入。
- 二进制下载采用「先下载到临时文件再原子 `mv`」的模式，并在 EXIT trap 中清理未完成的临时文件，保证幂等和回滚安全。
- 跨平台服务管理优先 systemd user unit，回退到 launchd（macOS）或自维护的后台 wrapper + crontab `@reboot` 钩子，卸载时同步清理三类持久化方式。

Skill 以 `SKILL.md` 作为入口契约，向宿主暴露环境变量（`AGENTFLOW_URL`、`AGENTFLOW_INSIGHT_TOKEN`、`AGENTFLOW_USAGE_FILE`）与两个 CLI 子命令：`--check` 仅校验输入 JSON，不带网络访问；默认模式则 POST 到 `/api/insights/v1/ingest`。

- `agents/openai.yaml` 提供 Agent 侧的显示名、短描述与默认 prompt，使该 Skill 可被 Agent 发现。
- `scripts/report_usage.py` 是纯 Python 3 标准库实现，职责分为三层：`validate_report` 按 `references/contract.md` 对记录字段、时间戳、usage 列表做严格校验；HTTP 层通过自定义 `NoRedirect` handler 禁用重定向并以指数退避重试 429/5xx；CLI 层解析参数并输出结构化结果。
- `references/contract.md` 与 `workflow-integration.md` 分别定义上报数据契约与工作流集成指引，脚本不直接引用它们，而是由 SKILL.md 在运行时指导宿主生成符合契约的 JSON。

依赖方向单向：SKILL.md → scripts → AgentFlow API；agents 与 references 仅被宿主/Agent 消费，不被脚本反向依赖。

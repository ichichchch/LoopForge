- 所有外部输入（JSON body、URL、Token、字段字符串）在进入 HTTP 请求前都经过 `validate_report` 或显式解析器校验，失败时抛出 `ValueError` 而非静默降级。
- 敏感凭据（Token、URL）一律从环境变量读取，禁止出现在日志、返回值或错误消息中。
- 网络调用采用指数退避 + 最大重试次数的重试策略，且对 400/401/403/409/413 等非临时错误立即失败，保留原始 JSON 文件交由宿主重试。
- CLI 同时支持 positional 参数与环境变量回退（如 `file` 与 `AGENTFLOW_USAGE_FILE`、`--url` 与 `AGENTFLOW_URL`），便于宿主以不同方式注入配置。

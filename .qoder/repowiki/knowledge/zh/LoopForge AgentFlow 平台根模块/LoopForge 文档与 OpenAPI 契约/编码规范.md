- 公开 API 契约以 `openapi.yaml` 为单一事实来源，Go 侧通过 `//go:embed` 将其作为只读字节数组注入，避免运行时 I/O。
- API 文档按领域拆分为独立 Markdown 文件（collaboration、registry、orchestration、shared-schedules、sync），并在 `api/README.md` 中以表格索引汇总所有端点。
- 对公共能力的断言通过 Go 测试完成：扫描 `openapi.yaml` 提取 `operationId` 与路径方法组合，与 `application.PublicOperations()` 返回的清单做双向一致性校验。
- 示例请求统一使用环境变量占位符（如 `$AGENTFLOW_URL`、`$AGENTFLOW_TOKEN`），不在文档中硬编码凭据。

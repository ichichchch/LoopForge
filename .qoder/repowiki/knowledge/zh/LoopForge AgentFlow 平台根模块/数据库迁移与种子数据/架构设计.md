目录采用纯 SQL 文件 + 数字前缀的线性迁移方案：根目录下 `001`~`035` 为 DDL/DML 迁移（ALTER TABLE、CREATE TABLE IF NOT EXISTS、INSERT IGNORE），子目录 `seed/` 下存放仅执行一次的种子数据（如公共 sandbox、generic_templates、workflows、agents）。每个迁移文件顶部以注释块说明背景、适用引擎（MySQL / sqlite）与幂等性约束；部分迁移（如 `001_run_obs_generated_columns.sql`）因依赖 MySQL STORED 生成列而不可重复执行，需运维在指定窗口手动运行。应用侧通过 gorm AutoMigrate 处理 Go struct 到表的增量同步，但显式把需要大表重建或引擎特定特性的变更剥离到此目录，由外部工具顺序执行。依赖方向单向：迁移 → 数据库，无反向引用。

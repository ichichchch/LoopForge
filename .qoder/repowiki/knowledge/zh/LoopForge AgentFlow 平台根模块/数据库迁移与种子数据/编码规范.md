- 迁移文件以三位数字序号命名（`NNN_<描述>.sql`），保证按语义顺序执行。
- DDL 使用 `CREATE TABLE IF NOT EXISTS` 与 `INSERT IGNORE` 实现幂等，使同一脚本可被重复执行而不报错。
- 每个迁移文件头部用中文注释块记录背景、适用引擎限制与幂等性说明，便于运维理解执行风险。
- 新表统一使用 `DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci`，主键 ID 采用 `VARCHAR(64)` 并配合 `created_at`/`updated_at DATETIME(3)` 时间戳列。
- 对外部关联字段（project_id、run_id、artifact_id 等）单独建索引（`KEY idx_<table>_<col>`）以支撑查询过滤。

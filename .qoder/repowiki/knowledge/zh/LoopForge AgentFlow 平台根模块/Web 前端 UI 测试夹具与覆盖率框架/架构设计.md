模块由三层构成：
- 夹具层 `lib/load-app.mjs`：通过 JSDOM 解析 `web/index.html`，按 `<script src>` 顺序用 `vm.Script.runInContext` 在隔离上下文内执行真实前端脚本；注入 `fetch`、`EventSource`、`WebSocket`、`ResizeObserver`、`IntersectionObserver`、`MutationObserver`、`matchMedia`、`requestAnimationFrame` 等浏览器 API 的桩实现，并提供 `createFetchRouter` 用于声明式 mock `/api/*` 路由及默认 bootstrap 数据。
- 测试层 `tests/*.test.mjs`：每个文件对应一个前端页面或组件（如 `flows-editor.test.mjs`、`issue-drawer-detail.test.mjs`），使用 `node:test` + `node:assert/strict` 调用 `loadApp()` 启动应用后断言 DOM 状态。
- 覆盖率层 `.c8rc.json` + `scripts/check-coverage.mjs`：c8 将 `../web` 下指定入口（app.js、knowledge.js、orchestrate.js、assistant.js、collaboration.js、chat-next.js）纳入统计，`check-coverage.mjs` 读取 `coverage-threshold.json`（当前 85%）校验行覆盖率是否达标。
依赖方向单向：tests → lib/load-app.mjs → web/ 源码；本模块不引入被测业务逻辑。

- 测试用例通过 `import { loadApp } from '../lib/load-app.mjs'` 启动应用，并在 `t.after(app.close)` 中释放 JSDOM 实例。
- 需要网络交互的测试通过 `loadApp({ routes: [{ method, path, body }] })` 注册 fetch 路由，而非直接替换全局 fetch。
- 异步 DOM 操作后使用 `await settle()` 等待多个微任务轮次完成后再断言。
- 选择下拉框时优先使用 `chooseOption(select, value)` 工具函数以绕过 jsdom 对 `HTMLSelectElement.value` 的属性拦截限制。

本模块是 Go 仓库的 `cmd/` 入口集合，每个子目录对应一个独立的二进制可执行文件，仅负责解析参数、加载配置并启动 `agentflow/internal/*` 中的业务逻辑：
- `cmd/agentflow`：主服务入口，通过 `-role`（api/worker/all）和 `AGENTFLOW_ROLE` 决定进程角色；`main.go` 组装 engine、httpapi、tracker、notification、preview 等内部组件，`handover.go` 实现基于 systemd socket 传递 + SIGHUP 的零停机热重载（`AGENTFLOW_LISTEN_FD` / `AGENTFLOW_READY_FD`），`cli.go` 封装 `managedcli` 的 status/update/rollback 子命令。
- `cmd/agentflow-gate-mcp`：极简门面，调用 `internal/gatemcp.Run` 处理 stdin/stdout MCP 协议。
- `cmd/agentflow-mcp`：远程 MCP 服务端，通过 `internal/mcpserver.ServeRemoteStdio` 连接上游平台，依赖 `AGENTFLOW_API_URL`。
- `cmd/agentflow-runner`：Runner 守护进程，出站 HTTPS 长轮询控制面，支持自动更新后 `syscall.Exec` 自重启，状态持久化到 state.json。
- `cmd/loopforge-account`：一次性本地管理员账号初始化工具，从 stdin 读取密码避免进入 argv。

所有二进制共享统一的 `.env` 加载约定（优先环境变量，其次工作目录及父级 `.env`），并通过 `runtime.RunMCPCallCLI` 统一拦截 MCP 调用子路径。

- 宿主能力通过 `editions.HOSTS` 与 `EDITION_SPECS[edition].hosts` 集中声明，新增宿主需同时更新该元数据与 `targets/<host>.py`。
- CLI 子命令统一采用 `argparse.add_subparsers` 注册，并在 `main()` 中以 `if args.command == ...` 分支分发，所有输出均支持 `--json` 开关。
- 文件写入前通过 `file_mode()` / `apply_mode()` 显式设置可执行位（`.sh` 自动加 `0o111`），避免依赖系统 umask。
- 运行时产物（`__pycache__`、`*.pyc`、`agent-observability/logs/*` 除 `.gitkeep`）在 `snapshot()` 中被过滤，不参与安装与打包。
- 宿主特定逻辑集中在 `core.materialize_<edition>(host, stage)` 内按 host 分支处理，adapter 脚本通过 `subprocess.run([sys.executable, installer])` 调用而非直接 import。
- 安装状态以版本化的 JSON（`STATE_VERSION` + `installer_version`）持久化到 `.devflow/install-state.json`，升级时校验版本字段。

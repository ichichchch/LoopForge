套件按被测面划分为四个并列目录：`api/`（基于 node:test 的 HTTP API 用例）、`ui/`（基于 @playwright/test 的真实浏览器用例）、`public/`（公共登录/语言/主题等回归 spec）和 `unit/`（纯 Node 单元测试）。共享基础设施集中在 `lib/`：`env.mjs` 集中解析 `AGENTFLOW_E2E_*` 环境变量并产出 `cfg`、`requireToken()`、`uid()`；`api.mjs` 提供 `api/get/list` 等 HTTP 客户端；`fixtures.mjs` 封装资源创建/清理；`version.mjs` 暴露版本信息。顶层 `run.sh` 是统一入口，按 `all/unit/api/ui` 参数顺序执行三类测试并在末尾兜底调用 `cleanup.mjs`；`local.sh` 则编译当前代码、拉起 MySQL + Runner + 沙箱容器并注入测试用户与 Token，用于本地验证未合并改动。Playwright 配置在根 `playwright.config.mjs`（指向 `ui/`，使用 `.auth/browser.json` 持久化会话），`public/` 另有独立的 `playwright.config.mjs`。所有测试资源通过 `cfg.prefix` + `cfg.runTag` 生成的唯一前缀命名，便于 `cleanup.mjs` 按运行标签回收。

- API 用例统一从 `../lib/api.mjs` 导入 `api/get/list`，从 `../lib/env.mjs` 导入 `cfg`，避免直接拼接 URL 或读取环境变量。
- 每个测试文件负责创建自身所需的资源并在结束时逆序清理，`run.sh` 仅在最后兜底执行一次 `cleanup.mjs`。
- 所有可写资源通过 `uid(label)` 生成带 `e2e-auto` 前缀和 `runTag` 的唯一 ID，便于按运行批次回收。
- 需要鉴权的请求通过 `{ auth: false }` 或伪造 `Authorization` / `Staffname` 头显式断言 401，以覆盖匿名与伪造身份边界。
- UI 用例使用 Playwright 的 `storageState` 加载由 `global-setup.mjs` 用真实密码登录写入的 `.auth/browser.json`，不在测试中 mock 登录接口。

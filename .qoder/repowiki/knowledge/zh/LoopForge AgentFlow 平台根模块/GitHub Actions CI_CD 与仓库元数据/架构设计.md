本模块是纯配置型 leaf，不含可执行代码，按职责拆分为四个子目录：
- `workflows/`：五个独立的工作流文件，分别承担不同阶段——`platform.yml`（Go 单元测试 + 真实 Chromium 浏览器测试 + 覆盖率门禁 + Playwright UI 验收）；`e2e.yml`（多 OS × Python × Node 矩阵端到端套件）；`validate.yml`（Python 3.8/3.12 校验、tcmcp 工具包、curl 安装冒烟、secrets 扫描）；`release.yml`（带 tag 校验、Docker Buildx 双架构镜像推送、GHCR 发布与 GitHub Release 创建）；`release-local.yml`（Local npm 包与 tcmcp 镜像发布）。
- `dependabot.yml`：对 github-actions、npm、pip、gomod 四类生态按月/周调度，仅允许 minor/patch 升级并分组聚合 PR。
- `repository-metadata.json`：集中声明仓库 description、topics 与 label 名称/颜色/描述，供 GitHub 仓库设置消费。
- `ISSUE_TEMPLATE/` 与 `pull_request_template.md`：贡献者引导模板，PR 模板内嵌了项目约定的验证命令集（go test/vet、check-public.py、local/scripts/*、scan-secrets.sh）。

依赖方向单向向外：工作流通过 `actions/checkout`、`setup-go/node/python` 等官方 action 拉取仓库源码后调用根目录下的 `scripts/*` 与 `local/scripts/*` 完成实际构建与测试，CI 本身不承载业务逻辑。

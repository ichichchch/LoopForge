- 视图脚本以 `renderXxx()` 命名导出，由 `app.js` 在路由切换或数据刷新后统一调用渲染。
- 所有后端请求走 `app.js` 中的 `api(path, options)` 封装，统一处理 JSON 响应、错误码与全局进度条。
- 用户交互替代 `alert/confirm/prompt`，全部通过 `afConfirm` / `afPrompt` / `afAlert` 队列化弹出，保证焦点与键盘无障碍。
- 状态集中维护于 `app.js` 顶层 `state` 对象，按功能域划分字段（如 `issueView`、`obsTab`、`mcpScope`），并通过 `localStorage` 持久化关键偏好。
- 每个功能模块遵循「同名 JS + 同名 CSS」成对组织（如 `workbench.js` + `workbench.css`、`issues.js` + `issues-list.css`），便于按视图拆分样式。
- 测试文件与源码并列放置，Go 测试用 `_test.go`，JS 测试用 `_test.js`，并配合 `*_harness_test.go` 启动真实 DOM 环境进行端到端断言。

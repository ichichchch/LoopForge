模块由三层组成：
- 资源层：`web/embed.go` 使用 `//go:embed` 将 `index.html`、`app.js`、`boot.js`、各视图 JS/CSS、`monaco/`、`vscode-web/`、`images/`、`mcp-icons/` 等静态资源打包进 Go 二进制；Go 侧仅负责 HTTP 路由与 JSON API（如 `/api/bootstrap`、`/api/runs`、`/api/auth/current`）。
- 运行时层：`boot.js` 在首屏设置 `data-lang` 与 `lang`，随后加载 `i18n.js` 与 `app.js`；`app.js` 定义全局 `state` 对象（runs/issues/tasks/workflows/projects/repositories/users/rules/skills/mcpServers/executors/dockerfiles/environments/sandboxes 等），并通过 `hashchange` 事件驱动视图切换（flow/projects/agents/runs/issues/approvals/assets/sops/observability/collaboration 等）。
- 功能子模块：`web/app/` 下每个文件对应一个领域（agents、approvals、assets、assistant-settings、bots、composer、dashboards、flow-*、issues、mcp、observability、projects、runs、sops、skillhub 等），通过 `window.<feature>` 暴露函数供 `app.js` 调用；UI 组件集中在 `hui-*.js`（select/date/upload/tooltip）和 `harness-ui.css` 设计系统。
依赖方向单向：功能子模块 → `app.js`（共享 state/api/toast/confirmModal/renderMarkdown）→ Go API；不反向引用。VS Code Web 与 Monaco 作为内嵌第三方资源，不被业务代码直接 import。

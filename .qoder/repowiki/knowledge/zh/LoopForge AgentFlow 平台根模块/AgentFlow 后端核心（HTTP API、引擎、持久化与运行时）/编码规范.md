- 每个包通过一个未导出的 `deps` 结构体承载共享依赖（如 `*gorm.DB`、`*repo.Store`、`*engine.Engine`），handler/Repo 类型以匿名指针嵌入该 deps 复用方法。
- 测试文件与源码同目录放置，命名遵循 `<source>_test.go` 或 `<source>_cases_test.go`/`*_split_test.go` 后缀，用于拆分大型测试套件。
- 跨组件协作通过函数字段回调而非接口注入（如 `engine.Engine` 上的 `MergeIntoBranch`、`WorkspaceCheckpointTransport`、`SetRunnerDispatchNotify`），nil 表示禁用或回退行为。
- 领域模型仅定义纯数据结构与校验方法，不持有 repo/engine 等副作用依赖；副作用统一放在 `httpapi`、`engine`、`repo` 三层。
- 对外暴露的服务通过构造函数返回 gin.Engine 或 Service 指针（如 `httpapi.New`、`engine.New`、`repo.newStore`），并在构造时完成依赖装配而非全局变量。
